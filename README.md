# Revelation

历史上的文学家、哲学家与思想者 — 静态人物图鉴（中 / 英）。

## 本地开发

```bash
npm install
npm run dev
```

打开提示的本地地址即可预览。

## 构建

```bash
npm run build
npm run preview
```

静态产物在 `dist/`，可部署到 GitHub Pages。

## 在线地址

发布后访问：<https://water43.github.io/revelation/>

## 新增人物

在 `src/content/figures/zh/` 与 `src/content/figures/en/` 各添加同名 Markdown，frontmatter 使用相同的 `slug`。
